The real product

This is not just an H3 loader.

The notebook wraps MiniMax H3 in a production environment designed around the things that normally make Colab painful: hardware differences, broken installs, memory limits, model residency, references, prompt structure, long-running jobs, and organizing the footage afterward.

Runtime

Automatic GPU profiles

Detects Blackwell, A100 80GB, A100 40GB, and T4-class hardware and selects a runtime and memory strategy for that card.

Blackwell

Private CUDA 13 fast path

Blackwell gets the dedicated CUDA 13 / SM120 path, MissingLink's prebuilt SageAttention wheel, attention benchmarking, and resident-stack optimization.

Low VRAM

T4 Dynamic VRAM mode

On T4-class cards the studio switches to a Q4_0 GGUF path with Dynamic VRAM and staged model handoff instead of pretending every GPU has 96GB.

Reliability

Self-healing setup

Validates model files, rejects incomplete weights, reuses working runtime targets, and keeps the selected PyTorch/CUDA stack from being silently replaced.

Control

Exact-duration output

Snaps generation to H3's legal frame grid, then retimes the finished video and audio together to honor the requested final duration.

Access

One MissingLink key

The studio validates the MissingLink key before expensive setup and periodically re-checks access while the UI is running.

Creative control

Two serious ways to drive the shot.

Use simple first/last keyframes when you want direct control, or move into the reference workflow when identity, motion, source footage, or audio need to survive across a more complex generation.

01 / CURRENT · KEYFRAMES

First frame + last frame

Use zero, one, or two image anchors. The studio can fit the canvas to the first frame, preserve aspect ratio, and generate a continuous path that lands on the requested ending frame.

First frame Last frame Cover / contain / stretch
02 / REF2VA · REFERENCES

Images, video, and audio references

Build a shot from a larger reference set instead of a single image. The current studio supports multiple image, video, and audio references and routes them through H3's reference workflow.

Up to 9 images Up to 3 videos Up to 3 audio refs
03 / COMMUNITY

Community LoRA workflow

Install compatible LoRAs into the running studio, stack multiple LoRAs with individual strengths, and keep the creative model layer inside the same Colab UI.

04 / SPEED + QUALITY

Runtime-aware acceleration

The studio can use acceleration and sparse-attention paths where the selected model and GPU support them, while retaining clean fallbacks when a fast path is incompatible.

Sparse attention Attention autotune Clean restart fallback
AI direction

Turn rough intent into an H3-ready shot.

Auto Prompt is optional. Raw Local remains the default, but when you want help the studio can visually inspect supplied reference frames and build H3's structured audiovisual prompt around motion, camera, dialogue, soundscape, music, and the exact start/end visual anchors.

01 / ROUGH IDEA

Describe the shot

Start with your own prompt, a first frame, a last frame, or a combination of references.

02 / VISION

Inspect references

Auto Prompt reasons over the supplied images instead of treating them as loose inspiration.

03 / DIRECT

Build the motion plan

Generate camera behavior, movement, shot order, soundscape, music, and dialogue structure.

04 / GENERATE

Send it to local H3

The final generation still runs through the local MiniMax H3 stack in your Colab runtime.

Production workflow

Keep working after the first clip.

The notebook has moved beyond one-shot generation. It keeps job state, history, projects, sequences, continuation frames, and a real GPU queue so a longer session behaves more like a small production tool.

Queue

Submit multiple renders

Queue jobs while another generation owns the GPU, inspect progress, clear waiting jobs, or request cancellation at safe boundaries.

Timeline

Build sequences

Generated clips become timeline segments with project and sequence state instead of disappearing into a downloads folder.

Continue

Use the previous last frame

The final frame of a finished clip can become the opening frame of the next queued continuation while preserving the canvas.

History

Recall and retry

Generation history tracks prompt, seed, dimensions, frames, duration, and stage images so earlier takes can be recalled or retried.

Projects

Save, load, duplicate

Project JSON, multiple sequences, duplication, reordering, and compilation give longer H3 sessions an actual structure.

Compile

Stitch the timeline

Sequence clips are combined into a master MP4 with stream-copy first and a normalized encode fallback when needed.
