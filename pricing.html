The stack we maintain

A working model is a chain, not a file.

A single mismatch can cost an entire GPU session: a wheel compiled for the wrong architecture, a PyTorch/CUDA pair that does not agree, an attention kernel that will not load, a quant that technically fits but leaves too little VRAM to generate, or a dependency update that breaks yesterday's notebook.

GPU→CUDA→PyTorch→attention→quant→memory→model→workflow

MissingLink Pro starts from configurations we have already tested together. When the ecosystem moves, the maintained runtime moves with it.
